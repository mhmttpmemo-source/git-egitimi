Konu 02: Repository Yapısı ve .gitignore

Tekrar dokümanı | Tarih: ____ / ____ / ______

Hedef: Repository yapısını anlamak, README dosyasını düzenlemek ve gizli veya gereksiz dosyaları Git'ten korumak.

1. Temel kavramlar

  • README.md: Projenin amacını, kurulumunu ve kullanımını açıklar.
  • .gitignore: Git'in takip etmemesi gereken dosya ve klasörleri belirtir.
  • Public repository: Herkesin görebildiği depodur.
  • Private repository: Yalnızca izin verilen kişilerin görebildiği depodur.

2. Güvenli .gitignore örneği

# Python
__pycache__/
*.py[cod]
.venv/
venv/

# Gizli bilgiler
.env
.env.*
!.env.example

# Veri ve editör dosyaları
*.csv
*.xlsx
.vscode/

Şifre, API anahtarı ve veritabanı parolası gibi bilgileri Public repository'ye gönderme.

3. Uygulama komutları

cd $HOME\git-egitimi
New-Item .gitignore
notepad .gitignore
git status
git add README.md .gitignore
git commit -m "README ve gitignore dosyalarını güncelle"
git push
git status

Beklenen sonuç: Son git status çıktısında yerel dalın origin/main ile güncel ve çalışma alanının temiz olduğu görülmelidir.
