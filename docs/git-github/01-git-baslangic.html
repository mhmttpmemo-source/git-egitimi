Konu 01: Git ve GitHub'a Giriş

Bu konunun hedefi: Git'in ne işe yaradığını anlamak, bir proje klasörünü Git ile takip etmek ve ilk commit'i oluşturmak.

1. Kısa özet

  • Git: Dosya değişikliklerini sürümler hâlinde takip eden dağıtık sürüm kontrol sistemidir.
  • GitHub: Git depolarını çevrim içi saklamaya ve birlikte geliştirmeye yarayan platformdur.
  • Repository: Projenin dosyaları ve Git geçmişinin bulunduğu depodur.
  • Commit: Değişikliklerin açıklamalı bir sürüm kaydıdır.

2. Komut kartı

# Git kurulumunu kontrol et
git --version

# Yeni proje klasöründe Git'i başlat
git init

# Değişiklikleri kontrol et
git status

# Dosyaları commit için hazırla
git add .

# İlk sürümü kaydet
git commit -m "İlk commit"

# Commit geçmişini görüntüle
git log --oneline

3. Uygulama görevi

  1. git-egitimi adında bir klasör oluştur.
  2. Klasörün içine README.md dosyası ekle.
  3. README dosyasına kendini ve öğrenme hedefini yaz.
  4. Git deposunu başlat ve ilk commit'i oluştur.
  5. git status ve git log --oneline çıktısını incele.

Beklenen sonuç: Çalışma klasöründe en az bir commit bulunmalı ve git status temiz çalışma alanı göstermeli.
