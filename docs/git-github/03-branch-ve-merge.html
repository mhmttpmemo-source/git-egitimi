Konu 03: Branch ve Merge

Tekrar dokümanı | Tarih: ____ / ____ / ______

Hedef: Yeni branch oluşturmak, değişiklik yapmak, merge etmek ve branch'i silmek.

1. Temel kavramlar

  • Branch (dal): Ana projeyi bozmadan ayrı bir çizgide çalışmaya yarayan yapıdır.
  • Feature branch: Yeni bir özellik eklemek için oluşturulan daldır.
  • Merge: Bir dalın değişikliklerini başka bir dala birleştirmektir.
  • Fast-forward merge: Çatışma olmadan birleştirme.

2. Branch komutları

git branch
git switch -c feature/isim
git switch main
git merge feature/isim
git branch -d feature/isim
git branch -v
git log --oneline

git branch dalları listeler, git switch -c yeni dal oluşturur ve ona geçer.

3. Uygulama adımları

  1. Yeni feature dalı oluştur: git switch -c feature/konu-03-pratik
  2. Dosya düzenle ve git add ile hazırla.
  3. Commit oluştur: git commit -m "açıklamacı mesaj"
  4. Main dalına dön: git switch main
  5. Merge et: git merge feature/konu-03-pratik
  6. Branch'i sil: git branch -d feature/konu-03-pratik
  7. GitHub'a gönder: git push

Beklenen sonuç: git log --oneline tüm commit'leri ve merge işlemini göstermeli.
